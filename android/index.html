Android 11 / Rockchip 4.19 系列核心

功能現況

Android 線以純 AOSP Developer Board 為對外方向，供客製 App、網路與 USB 週邊整合測試。保留系統設定、桌面、輸入功能及應用安裝能力。

  • v0.5 建立不含 Google 服務的 AOSP 基準。
  • v0.6 增加 USB UVC 相機整合，保留 Ethernet、USB 儲存與 NPU 支援。
  • v0.6.1 修正維修主控台輸出及外接 USB 相機的顯示方向。

v0.6.1 為最新已確認打包候選；完整可重建基準的同步確認及實板週邊回歸尚未全部完成。

驗證界線

v0.6 已完成系統內容檢查，v0.6.1 有成功建置與打包紀錄。相機預覽／重插、USB 碟讀寫、安全卸載、網路重連與 NPU 實際推論，仍須依該版本逐項回報，不能僅以功能已納入判定通過。

對外不包含 GMS、Play Store 或 Google Play services。應用以自有或已取得散布授權的 APK 為限。
